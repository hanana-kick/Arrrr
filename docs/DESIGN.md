# Doop → Android 0.3.2

원본 시안: https://doop.design/c/6DyH2NjWm7. 네이티브 UX는 사용자 피드백에 따라 업데이트되었습니다.

## 최상위 구조

전역 목적지는 **읽을거리 / 구독 / 설정**. 읽음·저장·피드·정렬은 읽을거리 필터로 유지합니다. 넓고 충분히 높은 창에서는 목록과 읽기 페이지를 좌우로 배치하며, 좁은 창에서는 목록에서 독립적인 전체 기사 페이지로 이동합니다. 화면 뒤에 목록을 띄우는 모달 시트, 시트 높이 확장 제스처, 다음 시트 탄성 전환은 모두 제거했습니다.

본문은 화면 끝까지 세로 스크롤하지만, 앱바·읽기 툴바 등 조작 버튼은 안전한 인셋 안에 위치합니다. 큰 제목이 위로 스크롤되면 앱바에 한 줄 말줄임 제목을 나타냅니다. 이전/다음 글은 명시적 버튼과 읽기 메뉴로 이동합니다. 스크롤은 글을 자동으로 넘기지 않으며, 이전 글로 돌아오면 글별 읽던 위치를 복원합니다.

## 전체 본문

RSS가 전체 글을 제공하면 그대로 표시합니다. 제공되지 않으면 기사 원본 URL의 공개 HTML을 한 번 요청해 본문·소제목·문단·이미지를 추출하고 SQLite v2의 별도 article_fulltext 표에 캐시합니다. JS나 임의 iframe/WebView 코드를 실행하지 않습니다. 실패 시 RSS 본문을 그대로 표시하고 재시도와 **원문 웹페이지 전체 보기**를 제공합니다. 유료 구독·로그인·JS 전용 페이지는 사이트가 공개한 범위를 넘어서 접근하지 않습니다. 이미지 로드는 원본 이미지 서버의 네트워크 정책 영향을 받을 수 있습니다.

## 호환성

기존 DB v1→v2 마이그레이션은 article_fulltext 테이블만 추가하며 RSS 구독·읽음·저장 상태를 유지합니다. MaterialExpressiveTheme와 읽기 테마(앱/라이트/종이/다크), 폰트·크기·줄간격 설정을 유지합니다. 네트워크 추출은 전체 피드 동기화가 아니라 글을 여는 시점에 수행합니다.
