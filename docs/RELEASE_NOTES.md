## Arrrr 0.3.0 preview

Doop에서 확정한 통합 읽을거리와 종이형 읽기 전환을 네이티브 Compose로 옮겼습니다.

- 하단/레일 목적지를 **읽을거리 · 구독 · 설정**으로 통합했습니다. 저장한 글은 필터에서 읽음 상태·출처·정렬과 함께 선택합니다.
- 큰 제목과 조건을 목록과 함께 스크롤하고, 낮은 창에서는 큰 제목을 생략합니다. 목록은 LazyColumn 가상화와 묶음 추가 표시를 사용합니다.
- 작은 창: 부분 읽기 시트로 열기 → 위로 스크롤해 전체 확장 → 본문 스크롤 → 끝에서 추가 직접 드래그 시 두 장 분리 → 놓으면 다음 글.
- 넓은 창: 모달 시트 대신 오른쪽 읽기 카드 안에서 동일한 전환. 이전 글로 돌아가면 읽던 항목과 위치를 복원합니다.
- 저장·읽기 테마·공유 툴바를 본문 위에 띄웠습니다. 끝 문장과 다음 버튼을 올려 읽을 수 있는 콘텐츠 여백을 유지합니다.
- 읽기 테마(앱/라이트/종이/다크)는 앱 색상과 별도로 저장합니다. 글꼴·배율·줄 간격을 같은 UI에서 조절합니다.
- 배경과 스크롤 영역은 edge-to-edge로 사용하고, 조작에는 시스템바·컷아웃 inset을 적용합니다.
- 설정의 상단바와 업데이트·테마·읽기 탭을 화면 크기에 관계없이 통일했습니다. 미리보기는 넓고 높은 창에서는 옆에, 작은 창이나 낮은 창에서는 버튼으로 열어 옵션 공간을 확보합니다.
- 다크 모드에서 별도 색상을 지정하지 않은 글자·아이콘도 Material Surface의 기본 전경색을 따르도록 수정했습니다.

### 설치

이 APK는 이전 0.2.0과 같은 applicationId 및 debug 인증서로 빌드하는 테스트용 프리뷰입니다. CI가 이전 릴리즈의 인증서와 일치하는지 검사합니다. versionCode는 3이며 기존 구독·기사·북마크 DB를 초기화하지 않습니다. production/Play 서명판은 아닙니다.

### 검증과 범위

CI는 RSS/Atom·필터·전환 로직 단위 테스트, lint, debug/release 빌드, API 35의 작은 창·넓은 창·낮고 넓은 창에서 네이티브 UI/드래그/저장소 테스트를 실행합니다. 설정 버튼을 실제 가시 영역까지 스크롤해 선택 상태와 영구 저장을 검사합니다. 스크린샷 ZIP을 릴리즈에 포함하며, 실패한 실행도 스크린샷과 로그를 아티팩트에 남깁니다. 실제 폴드 하드웨어·햅틱의 정밀 조율은 별도입니다.

현재 저장소는 기존 SQLite 캐시를 snapshot으로 읽으며, 목록은 그 캐시를 나눠 표시합니다. 데이터베이스 cursor/PagingSource 기반의 대규모 색인 페이징은 아직 아닙니다. 실시간 push 서버도 미연결이며 실제 갱신은 폴링입니다. RSS가 요약만 제공하면 해당 내용까지만 읽을 수 있습니다.

포인터 관성만으로 다음 글을 열지 않습니다. 동작 줄이기 설정에서는 큰 전환을 생략하고 이전·다음 버튼 경로를 사용할 수 있습니다.
