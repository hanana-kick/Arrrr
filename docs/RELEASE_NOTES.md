## Arrrr 0.2.0 preview

승인된 Doop 디자인을 Kotlin/Material 3 Expressive 네이티브 화면으로 구현했습니다.

- 모바일 하단 내비게이션과 폴더블의 목록·본문 분할 및 설정 화면
- 실제 RSS/Atom 추가·수집, 로컬 저장, 읽음·북마크, 검색과 피드별 필터
- 피드 이미지/파비콘, 이모지·Phosphor 사용자 지정
- 백그라운드/전경 폴링과 테마·동적 OS 색상·본문 표시 설정

첫 실행에서 피드를 추가하세요. 가상 샘플 기사는 제품에 포함하지 않았습니다.

**프리뷰 한계:** 실시간 push 수신 서버는 미연결이며 실제 업데이트는 폴링입니다. 이 APK는 debug 서명된 테스트용입니다. Play 배포용 서명은 구성하지 않았습니다. 백그라운드 확인 시각은 OS 절전·네트워크 제한에 따라 늦어질 수 있습니다. Fold8 실기기 테스트가 아닌 compact/expanded 에뮬레이터 검증입니다.

CI 결과와 네이티브 스크린샷은 저장소 Actions 실행에서 확인할 수 있습니다.
