## Arrrr 0.3.3 preview — RSS/Atom 본문 우선

- 긱뉴스 같은 Atom `content type="html"`, `content type="xhtml"` 및 RSS `content:encoded`에 포함된 본문을 우선 사용합니다. 요약만 제공하는 피드는 기존 공개 웹페이지 원문 추출을 유지합니다.
- 목록·문단·소제목·강조·클릭 가능한 HTTP(S) 링크·이미지를 웹뷰 없이 Jetpack Compose로 표시합니다. 스크립트·임베드·위험한 URL은 제거합니다.
- RSS 원본 본문 HTML을 별도 필드로 저장하여 재접속·재시작 후에도 유지합니다. SQLite v1/v2→v3 마이그레이션으로 기존 읽음·북마크·구독·수집된 원문 캐시를 보존합니다.
- 업그레이드 후 최초 피드 갱신에서 기존 조건부 요청 태그를 비우고 본문 HTML을 다시 수집합니다. 네트워크가 없어도 저장된 기존 글은 계속 열 수 있습니다.
- '원문 다시 가져오기'를 선택하면 웹페이지 원문을 별도로 요청할 수 있습니다.
- 피드가 제공하는 본문이 해당 매체의 외부 원본 기사 전체를 뜻하지 않을 수 있습니다. 특히 긱뉴스의 한국어 소개는 RSS로 제공되더라도 링크된 외부 원문과 별개입니다.
- API 35 에뮬레이터의 compact/wide/short UI 테스트, 단위 테스트, lint, 빌드가 모두 통과할 경우에만 프리뷰 APK를 게시합니다.

## Arrrr 0.3.2 preview

### 읽기 시트 제거, 전체 기사 페이지 복원

- 좁은 화면에서 기사 선택 시 일반적인 전체 페이지로 전환합니다. 시트·탄성 당김·시트 사이 자동 기사 넘김을 제거했습니다.
- 넓은 화면은 기존 목록·상세 분할을 유지하되, 오른쪽에 독립적인 기사 페이지를 표시합니다.
- 본문은 일반 스크롤이며 이전/다음 글은 버튼 또는 읽기 메뉴로 이동합니다. 글별 읽던 위치를 복원합니다.
- RSS가 요약만 제공하면 공개 원문 HTML에서 본문·소제목·사진을 추출하여 기기에 캐시합니다. 가져올 수 없는 경우 RSS 본문과 원문 웹페이지 열기를 제공합니다.
- 읽기 테마·글꼴·본문 크기·북마크·공유·큰/작은 제목 전환을 유지합니다.
- SQLite v1→v2 마이그레이션은 캐시 테이블만 추가하므로 기존 구독·저장 글·읽음 상태를 삭제하지 않습니다.

### 검증 및 제한

단위 테스트와 Android lint, Debug/Release 빌드, 컴팩트·와이드·낮고 넓은 창의 UI·저장 테스트가 모두 성공할 경우에만 프리뷰가 릴리즈됩니다. 기존 서명과의 일치도 확인합니다.

원문 수집은 공개 HTML에 한정됩니다. 로그인·유료 구독·JS만으로 표시되는 내용은 추출하지 않으며, 모든 사이트에서 원문 추출이 성공하는 것은 아닙니다. 본문 링크/복잡한 표·임베드 비디오 등은 원문 웹페이지에서 확인하세요. 이 APK는 Play 배포용이 아닌 debug 서명 테스트 버전입니다.
