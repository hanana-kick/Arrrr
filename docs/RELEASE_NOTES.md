## Arrrr 0.3.1 preview

### 제목 축소 시 헤더 깜빡임 수정

- 읽을거리 목록과 기사 읽기의 헤더가 제목 축소 시 순간 어두워졌다 밝아지는 현상을 수정했습니다.
- 투명 검정에서 배경색으로 보간하던 코드를 제거했습니다. 같은 Material Surface 색상을 유지한 채 불투명도만 전환합니다.
- 큰 제목/작은 제목 전환, Material 3 Expressive 모션, 읽기 시트와 카드, edge-to-edge, 툴바 배치는 유지했습니다.
- 라이트·종이·다크·검정 배경에서 접기/펼치기/도중 방향 전환의 색상 보간과 네이티브 앱바 중간 프레임을 검사하는 회귀 테스트를 추가했습니다.

### 설치와 검증

versionCode 4, versionName 0.3.1입니다. 기존 0.2/0.3 프리뷰와 같은 applicationId와 debug 인증서를 사용합니다. CI의 인증서 비교가 통과해야 릴리즈되며, 기존 DB를 초기화하지 않습니다. 앱을 삭제하지 말고 업데이트 설치하세요.

작은 창(360×800dp), 넓은 창(1020×770dp), 낮고 넓은 창(900×400dp)의 기존 UI·드래그·저장 테스트와 새 앱바 렌더링 테스트, 단위 테스트, lint, Debug/Release 빌드를 모두 통과한 경우에만 게시합니다. 릴리즈의 APK는 Debug 서명된 테스트용이며 Play 배포용 production 서명판이 아닙니다.

기존 0.3의 범위는 같습니다. 실제 폴드 기기의 감도·햅틱은 별도 검증이며, 실시간 푸시 서버는 미연결이고 갱신은 폴링입니다. 목록은 로컬 snapshot을 묶음 표시하며 DB cursor 기반 대규모 페이징은 아직 아닙니다.
